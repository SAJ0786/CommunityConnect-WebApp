Next Steps — Android App Launch
1
Install Tools

Install Android Studio, Bubblewrap CLI and Java JDK 11+. These are free tools required to build the APK.

2
TWA Setup

Run bubblewrap init using the app manifest from communityevents.siza.info to configure the Android wrapper.

3
Build & Sign APK

Run bubblewrap build to generate a signed APK/AAB file. Store the signing keystore safely — it's needed for all future updates.

4
Play Store Launch

Create a Google Play developer account ($25 one-time fee), upload the AAB, fill in store listing and submit for review.

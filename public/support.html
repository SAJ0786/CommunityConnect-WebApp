Common Questions

How do I add an event?
Log in and tap Add Event in the bottom navigation bar. Choose Single Event, or if you are an Admin/Super Admin choose Recurring Event. Fill in the mandatory date, time and address details, then submit. After saving, the form closes and the event appears on the Home screen.

What is a recurring event?
Recurring events are for repeated programs. Admins and Super Admins can repeat an event daily, weekly, monthly or yearly, preview the generated dates, and then create all occurrences in one action. Normal users can see this option but it is disabled for them.

Can I use prayer time instead of a fixed time?
Yes. In the event form, choose Prayer Time (Variable), select the prayer name, and optionally add an offset in 30-minute steps. The app calculates the time from the event date and selected address GPS location. If you want an exact manually entered time, choose Fixed Time.

What is the difference between Centre and Private events?
Centre events are public community events hosted by an organisation. Private events are hosted by individuals. Both are visible to all logged-in users, but private event full addresses and host phone numbers are only shared by the host or admins.

Can I add an event on behalf of someone else?
Yes. Tick "I am adding this event on behalf of someone else" when filling in the event form.

How do I go live?
Open one of your events, tap Go Live, choose Public or Private, choose the required orientation, then start the stream. Public streams show a "Watch on YouTube" button on the event card within about 15-20 seconds. Private streams use YouTube unlisted/link-only visibility and are not shown as public stream links in the app. Private stream links may be emailed to the host once the stream is live.

Why is my event still showing as LIVE after I stopped streaming?
Tapping "End Stream" and confirming should clear the LIVE status everywhere within a few seconds. If an event remains stuck as live (for example after a crash or lost connection), it will be automatically cleared within a couple of minutes. If it's still stuck after that, contact us and we can manually reset it.

Can multiple events be live at the same time?
Yes. Each event streams independently to its own YouTube broadcast, so multiple events can go live simultaneously without interfering with each other.

Why does my phone stay on while I'm live?
The app keeps your screen awake automatically while streaming so the broadcast doesn't get interrupted by your phone locking. Switching to another app or manually locking your phone will still pause the broadcast — keep the streaming screen open until you tap "End Stream".

How do I sync events to my calendar?
Go to the Calendar tab and use the calendar sync option. Supported browsers/devices can open the subscription directly; where a native wrapper or browser blocks direct opening, the app provides a calendar feed URL or downloadable calendar file as a fallback.

How does the map view work?
Logged-in users can switch between List and Map views on Home. The map shows event locations from the saved event address coordinates and uses marker colours for audience type. Guest users cannot access Map view.

How do I turn off email reminders?
Go to Profile and toggle Email Reminders off. Admin and Super Admin users can also turn off administrator-level alert emails separately.

How do I hide an event temporarily?
In My Events, tap the eye icon on any event to toggle its visibility. Hidden events are not shown on the home screen and are excluded from all reminders and notifications — but you can still share them privately. Tap Share on a hidden event to send it directly to specific people; anyone you don't share it with will never see it in the app.

What is Bulk Share?
Bulk Share lets you select several upcoming events at once and generate a formatted message listing all of them. You can choose detailed or brief format. Messages are grouped into Centre Programs and Private Programs where applicable.

How do I use AI Search?
Tap the AI Search tab and type or speak your query. You can ask things like "Majlis in Sydney this weekend" or "ladies programs near me". If an AI response looks unsafe, incorrect or inappropriate, use the report option so it can be reviewed.

How do I delete my account?
Go to Profile - Delete My Account. This deletes your user account and profile details, but events you created are retained as event history. You can choose whether your active events become inactive immediately or remain active until their normal expiry date. See also: Account Deletion Policy.

Where can I install the app?
The app is available on the Apple App Store, Google Play and Microsoft Store. Use Install Community Events Australia or the store links shown on the login page.

Reporting Inappropriate Content: If you see an event with inappropriate or misleading information, please contact us at communityeventssydney@gmail.com with the event details.

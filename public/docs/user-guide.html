User Guide

Community Events – Create · Share · Connect

What is Community Events?

Community Events helps you discover, share and manage local community events including Majlis, Milad, birthdays and informal gatherings.

Login → View Events → Add Event → Search → Sync Calendar → Get Reminder

🔐 Step 1 – Login

Sign in with Google or Email. First time users must accept the Privacy Policy and Terms of Use before accessing the app.

🏠 Step 2 – View Events

The Home screen shows all upcoming events. Use the quick buttons — Today, This Week, This Weekend, Nearby — to filter instantly.

➕ Step 3 – Add an Event

Tap Add in the bottom navigation. Fill in: Host Name, Date & Time, Full Address, Event Type, Audience Type.

If the event type is Majlis or Milad, you can also add a Speaker and multiple Reciters (e.g. Soz, Salam, Noha, Manqebat).

After selecting the date, the Hijri calendar date is shown automatically.

Tick "Adding on behalf of someone else" if you're submitting for another host – you'll still own and manage that event.

🔍 Step 4 – Search Events

Search and filter by: date range, host name, suburb, event type, and audience type. Enable Nearby (10km) to find events close to your current location.

📅 Step 5 – Calendar Sync

Go to Calendar, select a date range, then tap Download Calendar File. Open the .ics file to import into iPhone Calendar, Google Calendar, or Outlook.

Calendar entries include: host name, event type, date & time, address and audience type. Speaker and reciter details are not included in calendar entries.

🔔 Step 6 – Email Reminders

A daily email is sent for events happening today, including full details with reciters. Toggle reminders on/off anytime in Profile.

✏️ My Events

Go to My Events to see and manage all events you created. You can edit or delete any of your own events at any time.

User Roles

👤 User

Add, edit and delete their own events. View all events and sync calendars.

🛠 Admin

All User permissions plus: edit and delete any event, adjust Hijri calendar settings.

👑 Super Admin

All Admin permissions plus: manage user roles, promote or demote users. Cannot remove themselves as the last Super Admin.

Important Notes

  • Events are automatically removed from the app 7 days after their date.
  • Calendar entries show basic info only. Full details are always available in the app.
  • Deleting your account permanently deletes all your events.

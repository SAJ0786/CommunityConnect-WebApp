Next Steps — Android App (Implement in Order)
1
Install Tools — Android Studio, Bubblewrap CLI (npm install -g @bubblewrap/cli) and Java JDK 11+. All free.
2
Initialize TWA — Run bubblewrap init --manifest=https://communityevents.siza.info/manifest.json to configure the Android wrapper using your existing web app.
3
Build & Sign APK — Run bubblewrap build to generate a signed APK/AAB. Keep the signing keystore safe — required for all future updates.
4
Play Store Listing — Create Google Play developer account ($25 one-time). Upload AAB, fill store listing with screenshots and privacy policy URL, submit for review (3–7 days).
5
Add Android OAuth — In Google Cloud Console, create OAuth client ID for Android with package name and SHA-1 fingerprint so Google login works in the native app.
6
Deploy Updates — After launch, run firebase deploy --only hosting to update the app. TWA automatically serves the latest version — no app store resubmission needed.

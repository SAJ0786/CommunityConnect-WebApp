Next Steps — Android App (Implement in Order)
  • 1
    Install Required Tools — Download and install Android Studio, Bubblewrap CLI (npm install -g @bubblewrap/cli) and Java JDK 11+. All free tools.
  • 2
    Initialize TWA Project — Run bubblewrap init --manifest=https://communityevents.siza.info/manifest.json. This reads your existing web app manifest and configures the Android wrapper automatically.
  • 3
    Build & Sign the APK — Run bubblewrap build to generate a signed APK/AAB file. Bubblewrap creates a signing keystore for you — store it safely as it is required for all future app updates.
  • 4
    Create Play Store Listing — Create a Google Play developer account ($25 one-time fee). Upload the AAB file, fill in the store listing (description, screenshots, privacy policy URL) and submit for review. Usually approved within 3–7 days.
  • 5
    Add New OAuth Credentials — In Google Cloud Console, create a new OAuth client ID of type Android with your app's package name and SHA-1 fingerprint from the signing key. This allows Google login to work in the native app.
  • 6
    Test & Deploy Updates — After launch, deploy web updates via firebase deploy --only hosting — the TWA app automatically serves the latest version. No app store resubmission needed for content updates.
